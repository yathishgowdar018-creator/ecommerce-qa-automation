# BUG-003: Blank page and no error message when the app fails to load (HTTP 500)

| Field | Value |
|-------|-------|
| **Bug ID** | BUG-003 |
| **Title** | Blank page and no error message when the app fails to load (HTTP 500) |
| **Severity** | Medium |
| **Priority** | Medium |
| **Environment** | Chrome (latest), https://www.saucedemo.com, simulated with Playwright `page.route()` |
| **Status** | Open |

## Preconditions
None.

## Steps to reproduce
1. Intercept requests to `/static/js/*.js` and return HTTP 500
2. Open https://www.saucedemo.com

## Expected result
A friendly message such as "Something went wrong, please try again" is shown.

## Actual result
The page stays blank. The user gets no feedback and no way to retry.

## Evidence
Automated test: `web-automation/tests/resilience.spec.ts` -> *server failure (500)* (marked `test.fail`).
