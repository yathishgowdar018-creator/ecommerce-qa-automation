# BUG-004: Checkout is allowed with an empty cart

| Field | Value |
|-------|-------|
| **Bug ID** | BUG-004 |
| **Title** | Checkout is allowed with an empty cart |
| **Severity** | Medium (tester's assessment) |
| **Priority** | Medium (tester's assessment) |
| **Environment** | Chrome, https://www.saucedemo.com, 06-Oct-2026 |
| **Affected component** | Cart page, Checkout button |
| **Status** | Open |

## Preconditions
User `standard_user` / `secret_sauce` is logged in and the cart contains no products.

## Steps to reproduce
1. Open https://www.saucedemo.com and log in as `standard_user`
2. Do not add any product
3. Click the cart icon
4. Click **Checkout**

## Expected result
Checkout is not started while the cart is empty (the user stays on the cart page).

## Actual result
The application navigates to "Checkout: Your Information".
